# 🚀 Быстрая справка - Система версионирования

## 📦 Основные команды

### Обучение
```bash
python run_training.py
# Создает новую версию модели (v001, v002, v003, ...)
```

### Просмотр моделей
```bash
python model_manager.py list
# Показывает таблицу всех моделей с метриками
```

### Использование модели
```bash
# Интерактивный выбор (рекомендуется)
python run_inference.py

# Указать версию
python run_inference.py --model-version 3

# Указать путь
python run_inference.py --model-path ./models_archive/v003_...
```

---

## 🔍 Управление моделями

```bash
# Информация о модели
python model_manager.py info --version v003_20241218_163045

# Сравнить две модели
python model_manager.py compare --version v001_... --version2 v003_...

# Найти лучшую модель
python model_manager.py best --metric mae
python model_manager.py best --metric rmse
python model_manager.py best --metric r2

# Экспортировать модель
python model_manager.py export --version v003_... --output ./my_model

# Удалить модель
python model_manager.py delete --version v001_...
```

## 🎯 Типичные сценарии

### Сценарий 1: Первое обучение
```bash
python run_training.py          # v001 создана
python model_manager.py list    # Проверить результаты
python run_inference.py         # Выбрать v001, Enter
```

### Сценарий 2: Улучшение модели
```bash
# Измените config.py (например, dropout=0.2)
python run_training.py          # v002 создана
python model_manager.py compare --version v001_... --version2 v002_...
python model_manager.py best    # Найти лучшую
```

### Сценарий 3: Эксперименты
```bash
# Эксперимент 1
python run_training.py          # v003: attention=True

# Эксперимент 2
python run_training.py          # v004: attention=False, layers=2

# Эксперимент 3
python run_training.py          # v005: bidirectional=True

python model_manager.py list    # Сравнить все
python model_manager.py best --metric r2  # Выбрать лучшую
```

### Сценарий 4: Production
```bash
# Найти лучшую модель
python model_manager.py best --metric mae

# Экспортировать для использования
python model_manager.py export --version v005_... --output ./production

# Проверить
python run_inference.py --model-path ./production
```

## 📊 Метрики

| Метрика | Описание | Лучше |
|---------|----------|-------|
| **MAE** | Средняя ошибка | ↓ Меньше |
| **RMSE** | Корень средней квадратичной ошибки | ↓ Меньше |
| **R²** | Коэффициент детерминации | ↑ Больше |

**Целевые значения:**
- MAE < 0.35
- RMSE < 0.60
- R² > 0.65

## ⚡ Быстрые советы

### Чтобы не забыть версию
```bash
# В README каждой модели есть команда для запуска:
cat models_archive/v003_*/README.txt
# → python run_inference.py --model-version 3
```

### Автоматический выбор лучшей
```bash
# Найти и использовать лучшую модель
BEST=$(python model_manager.py best --metric mae | grep -oP 'v\d+')
python run_inference.py --model-version ${BEST:1}
```

### Backup моделей
```bash
# Скопировать все модели
cp -r models_archive models_archive_backup_$(date +%Y%m%d)
```

### История экспериментов
```bash
# Посмотреть хронологию
python model_manager.py list | sort

# Только недавние (сегодняшние)
python model_manager.py list | grep $(date +%Y-%m-%d)
```

## 💡 Pro Tips

1. **Коммитьте config.py перед обучением** - будете знать какие параметры использовались
2. **Делайте заметки** - добавляйте комментарии в config.py о том, что меняли
3. **Не удаляйте модели сразу** - может понадобиться откат
4. **Экспортируйте лучшие модели** - отдельно от архива
5. **Проверяйте inference сразу** - после обучения сделайте тестовое предсказание
