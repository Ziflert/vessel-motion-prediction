# 📦 Система версионирования моделей

## 🎯 Обзор

Теперь каждая обученная модель сохраняется в **уникальную папку** с номером версии и timestamp. Модели **никогда не перезаписываются**.

---

## 📁 Структура хранения

```
./models_archive/
├── v001_20241218_143052/          ← Версия 1
│   ├── checkpoints/
│   │   ├── best_model.pt          ← Веса модели
│   │   └── scalers.pkl            ← Нормализаторы

    └── ...
```

## 🚀 Использование

### 1. Обучение новой модели

```bash

```

**Что происходит:**
- ✅ Создается новая папка `v00X_timestamp/`
- ✅ Модель обучается

- ✅ Генерируется отчет

### 6. Поиск лучшей модели

```bash
# По MAE (минимум лучше)
python model_manager.py best --metric mae

# По RMSE
python model_manager.py best --metric rmse

# По R² (максимум лучше)
python model_manager.py best --metric r2
```

---

### 7. Экспорт модели

```bash
python model_manager.py export --version v003_20241218_163045 --output ./exported_model
```

Копирует модель в отдельную папку для развертывания или передачи.

---

### 8. Удаление модели

```bash
python model_manager.py delete --version v001_20241218_143052
```

⚠️ **Внимание:** Удаление необратимо! Программа попросит подтверждение.

## 🔄 Типичный workflow

### Эксперименты с параметрами

```bash
# 1. Baseline модель
python run_training.py
# → Создается v001 с дефолтными параметрами

# 2. Изменяем config.py (увеличиваем dropout)
# encoder_dropout = 0.2
python run_training.py
# → Создается v002

# 3. Изменяем config.py (добавляем attention)
# use_attention = True
python run_training.py
# → Создается v003

# 4. Сравниваем результаты
python model_manager.py list
python model_manager.py compare --version v001_... --version2 v003_...

# 5. Выбираем лучшую
python model_manager.py best --metric r2

# 6. Используем лучшую для inference
python run_inference.py --model-version 3
```

## 🎯 Преимущества системы

### ✅ Воспроизводимость
- Каждая модель сохраняется со всеми параметрами
- Можно вернуться к любой версии
- Легко сравнить разные эксперименты

### ✅ Отслеживание прогресса
- История улучшений видна в списке моделей
- Сравнение показывает, что помогло
- Метрики сохранены для анализа

### ✅ Безопасность
- Старые модели не теряются
- Можно откатиться к предыдущей версии
- Нет риска потерять лучшую модель

### ✅ Совместная работа
- Легко делиться конкретными версиями
- Ясная нумерация и timestamp
- Полная документация для каждой модели

## 🔧 Дополнительные команды

### Быстрые команды

```bash
# Последняя модель (latest)
python run_inference.py  # просто Enter при выборе

# Лучшая модель
python model_manager.py best

# Список с фильтрацией (через grep)
python model_manager.py list | grep "2024-12-18"

# Быстрый просмотр README
cat models_archive/v003_*/README.txt
```

### Автоматизация

```bash
# Обучить несколько моделей подряд
for i in {1..5}; do
    # Изменить параметры в config.py
    python run_training.py
done

# Найти лучшую автоматически
BEST=$(python model_manager.py best --metric mae | grep "Best model" | cut -d' ' -f4)
python run_inference.py --model-version $BEST
```
