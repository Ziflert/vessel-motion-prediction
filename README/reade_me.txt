# 🚢 Vessel Motion Prediction - Usage Guide

## 📋 Быстрый старт

### 1. Просмотр текущей конфигурации
```bash
python config/switch_config.py
```

### 2. Выбор профиля предсказания

#### Доступные профили:

| Профиль | Описание | Целей | Что предсказывает |
|---------|----------|-------|-------------------|
| **motion** | Качка судна | 6 | Pitch, Roll, Vertical + velocities |
| **rot** | Поворот судна | 1 | ROT (Rate of Turn) |
| **speed** | Скорость судна | 1 | SOG (Speed Over Ground) |
| **full** | Всё вместе | 8 | Качка + ROT + SOG |

#### Переключение профиля:
```bash
# Предсказание только качки
python config/switch_config.py profile motion

# Предсказание только поворота (ROT)
python config/switch_config.py profile rot

# Предсказание всего
python config/switch_config.py profile full
```

### 3. Выбор режима скорости

| Режим | Complexity | Скорость | Качество | Время |
|-------|-----------|----------|----------|-------|
| **fast** | 2,400 | ⚡⚡⚡⚡ | ⭐⭐⭐ | ~1 час |
| **balanced** | 5,400 | ⚡⚡⚡ | ⭐⭐⭐⭐ | ~2-3 часа |
| **quality** | 18,000 | ⚡⚡ | ⭐⭐⭐⭐⭐ | ~6-8 часов |

```bash
# Быстрый режим для экспериментов
python config/switch_config.py speed fast

# Рекомендуемый режим для production
python config/switch_config.py speed balanced

# Максимальное качество
python config/switch_config.py speed quality
```

### 4. Запуск обучения
```bash
python run_training.py
```

## ⚙️ Ручная настройка (Advanced)

### Редактирование config/config.py

#### 1. Custom профиль
```python
# В config/config.py
profile: str = "custom"

feature_columns: List[str] = field(default_factory=lambda: [
    'Wave.Highest(метры)',
    'Wind.direction(градусы)',
    'Rudder State(градусы)',
    # ... ваши признаки
])

target_columns: List[str] = field(default_factory=lambda: [
    'Roll(градусы)',
    'Pitch(градусы)',
    # ... ваши цели
])

target_weights: Dict[str, float] = field(default_factory=lambda: {
    'Roll(градусы)': 3.0,   # Крен ОЧЕНЬ важен
    'Pitch(градусы)': 1.0,  # Дифферент менее важен
})
```

#### 2. Изменение весов существующих профилей
```python
# В Config.get_profile_config(), секция 'full_prediction'
'weights': {
    'Roll(градусы)': 5.0,  # Увеличили вес крена
    'Pitch(градусы)': 1.0,
    'ROT(°/мин)': 2.0,     # Увеличили вес ROT
    # ...
}
```

#### 3. Настройка архитектуры модели
```python
# Для более сложной модели
temporal_hidden_size: int = 256      # Было 128
temporal_num_layers: int = 3         # Было 2
decoder_hidden_dim: int = 128        # Было 96

# Для более быстрой модели
temporal_hidden_size: int = 64       # Было 128
temporal_num_layers: int = 1         # Было 2
```

## 📊 Веса целевых переменных

### Что это?
Веса определяют, насколько важна каждая переменная при обучении.

### Как работают?
- `weight = 1.0` - нормальная важность
- `weight = 2.0` - **в 2 раза важнее** (loss удваивается)
- `weight = 0.5` - **в 2 раза менее важна**

### Пример влияния весов:
```python
# Без весов (всё равнозначно)
Loss = MSE(Roll) + MSE(Pitch) + MSE(ROT)

# С весами
Loss = 2.0 * MSE(Roll) + 1.0 * MSE(Pitch) + 1.5 * MSE(ROT)
#      ^^^^              ^^^^                ^^^^
#      важнее!           норма              чуть важнее
```

### Когда менять веса?

**Увеличьте вес**, если переменная:
- Критически важна для безопасности (например, Roll)
- Плохо предсказывается
- Имеет большую амплитуду изменений

**Уменьшите вес**, если переменная:
- Второстепенна
- Легко предсказывается
- Имеет малую амплитуду

## 💡 Советы по настройке

### 1. Начните с профиля "full" + режима "fast"
```bash
python config/switch_config.py profile full
python config/switch_config.py speed fast
python run_training.py
```
Это даст базовое понимание качества предсказаний.

### 2. Анализируйте "Top 3 worst variables"
Если какая-то переменная постоянно в топе худших:
- Увеличьте её вес в `target_weights`
- Проверьте, есть ли достаточно признаков для её предсказания

### 3. Для ROT важны:
- `Rudder Order/State` (причина поворота)
- `SOG` (скорость влияет на эффективность руля)
- `Wave.direction`, `Current.direction` (внешние силы)

### 4. Для качки (Roll, Pitch) важны:
- `Swell`, `Wave.Highest` (основная причина)
- `Wave.direction` (откуда идут волны)
- `SOG`, `Course` (влияют на взаимодействие с волной)

### 5. Если обучение слишком долгое:
```bash
# Уменьшите sequence_length
sequence_length: int = 100  # Было 150

# Уменьшите prediction_horizon
prediction_horizon: int = 15  # Было 20

# Упростите модель
temporal_hidden_size: int = 64  # Было 128
temporal_num_layers: int = 1    # Было 2
```

## ❓ FAQ

**Q: Какой профиль выбрать для начала?**
A: `full` - он покажет, что модель умеет предсказывать всё.

**Q: Почему ROT предсказывается хуже качки?**
A: ROT зависит от решений экипажа (руль), которые могут быть непредсказуемы. Качка зависит от волн - более стабильный паттерн.

**Q: Можно ли комбинировать профили?**
A: Используйте `profile = "custom"` и задайте свой список целей.

**Q: Как ускорить обучение?**
A: Режим `fast` + уменьшите `sequence_length` и `temporal_hidden_size`.

**Q: Модель переобучается (val loss растёт)?**
A: Увеличьте `dropout` (0.15 → 0.2) или уменьшите `temporal_hidden_size`.
