## 📊 Веса целевых переменных (в config/config.py)

### По умолчанию для profile="full":
```python
'Roll(градусы)': 2.0,      # ← Крен ВАЖНЕЕ (самое опасное)
'Pitch(градусы)': 1.0,
'Vertical(Метр)': 1.5,
'ROT(°/мин)': 1.5,
'SOG(узлы)': 1.0,
# ... остальные
```

### Как изменить веса:
1. Открыть `config/config.py`
2. Найти `Config.get_profile_config()`
3. Изменить значения в секции `'weights'`
4. Перезапустить обучение

## 🎛️ Основные параметры (config/config.py)

```python
# Временные параметры
sequence_length: int = 150        # История (в шагах)
prediction_horizon: int = 20      # Предсказание вперёд

# Архитектура
temporal_hidden_size: int = 128   # Размер LSTM
temporal_num_layers: int = 2      # Количество слоёв

# Обучение
batch_size: int = 32
learning_rate: float = 0.0005
num_epochs: int = 150
```

## 💡 Советы

### Если модель обучается долго:
```bash
python config/switch_config.py speed fast
# или в config.py:
sequence_length: int = 100  # уменьшить
temporal_hidden_size: int = 64  # упростить
```

### Если качество низкое:
```bash
python config/switch_config.py speed quality
# или в config.py:
temporal_hidden_size: int = 256  # увеличить
temporal_num_layers: int = 3  # добавить слоёв
```

### Если переобучение (val loss растёт):
```python
# В config.py:
encoder_dropout: float = 0.2  # увеличить (было 0.15)
temporal_dropout: float = 0.15  # увеличить (было 0.1)
```

## 📈 Мониторинг обучения

### Хорошие признаки:
- ✅ Val loss медленно снижается
- ✅ R² > 0.85 на тесте
- ✅ MAE стабилизируется
- ✅ "Top worst variables" меняются со временем

### Плохие признаки:
- ❌ Val loss растёт (переобучение)
- ❌ Train loss не падает (слабая модель)
- ❌ R² < 0.5 (модель не учится)
- ❌ Одна переменная всегда худшая (плохие признаки)

## 🚨 Troubleshooting

| Проблема | Решение |
|----------|---------|
| `CUDA out of memory` | Уменьшить `batch_size` |
| Слишком долго | Режим `fast` или уменьшить `sequence_length` |
| Низкое качество ROT | Увеличить вес `'ROT(°/мин)': 3.0` |
| Низкое качество Roll | Увеличить вес `'Roll(градусы)': 5.0` |
| Переобучение | Увеличить `dropout` до 0.2-0.25 |
