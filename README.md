# ⚓ Vessel Motion Prediction — прогноз качки судна (LSTM/Seq2Seq)

Data-driven система прогнозирования поведения судна на волнении: **Seq2Seq (MLP → LSTM-энкодер ×2 → attention → LSTM-декодер)** на PyTorch. Вход — окно истории бортовых датчиков (1 Гц), выход — прогноз на 20 шагов по 8 целям (Pitch, Roll, Vertical, их скорости, ROT, SOG). Плюс **онлайн-система** (playback/live, детекторы аномалий, дообучение) и **веб-панель управления**.

> Научная база: `CONCEPT.md` (замысел: датчики → маркировка судоводителем → большая база → LSTM → СППР; инвариант «одно судно × одна загрузка»; покрытие пространства условий Ω). Журнал экспериментов: `RESEARCH_LOG.md`.

## 📊 Главные результаты (подробности и методика — `RESEARCH_LOG.md` §5)

| Эксперимент | Результат |
|---|---|
| **H1: learning curve** | качество растёт с объёмом по степенному закону **MAE ≈ 47·n^(−0.20)** (−12.5% на удвоение); плато не достигнуто — данных не хватает |
| **H2: синтетика** | чистая синтетика (train-fit) R² ≈ 0.63 на реальном тесте ≈ 99 мин реальной записи; **аугментация «12 мин реала + 2.4 ч синтетики» R² 0.60+ > 99 мин чистого реала** |
| **Sweep коэффициентов** | эффекты зависят от объёма: на малых данных всё в шуме; на больших — smoothness-loss вредит (−0.34 при 3 сидах), attention критичен (+0.94 без него) |
| **Мультисид** | одиночный сид переоценивает эффекты; знаки выводов устойчивы по сидам 42/43/44 |

Рисунки для статьи (PDF+PNG 300 dpi, строятся одним прогоном из готовых данных):
`results/article/figs_v2/fig1…fig7` — кривая обучения + степенной закон, sweep, per-target, режимы волнения, дрейф периода качки.

## 🧭 Критические факты о данных (важно до любых экспериментов)

- запись `data/raw/your_data.csv` — **сценарий нарастающего шторма**: строки 0–4000 «мёртвые» (штиль), исследование ведётся на активном регионе (строки 4000+);
- `Wave.Highest` — рампа/сатурация (не измерение!), `Wave.direction ≡ 180°` — канал причины качки вырожден;
- период качки дрейфует со штормом (Roll ≈ 8.3 → 16 с);
- **инвариант «судно × загрузка»**: нельзя смешивать в одном дата-сете записи разных состояний загрузки и тем более разных судов (CONCEPT §3).

## 🧪 Воспроизводимость

Все прогоны регистрируются в реестре (`registry.py`): `manifest.json` фиксирует данные (sha256), сплит, гиперпараметры, скалеры и результаты. Скалеры фиксированные (`--fixed-scaler`), тест неизменен между экспериментами, выбор по val, не по test. Мультисид — `--seed`/`scripts/sweep.py --seeds`.
